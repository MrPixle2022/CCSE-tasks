# Arduino task 2

this task asks for us to read input from the user using the serial monitor to pass inputs, the input is used to apply certain control,the inputs are as follows:

- if user inputs `1` control becomes:
  potentiometer controls the blink speed of an LED
- if user inputs `2` control becomes:
  LED brightness by the read value of an LDR
- if user inputs `3` control becomes:
  while button is pressed, the LED is ON
- (extra, was not required) if user inputs `4` the control becomes:
  the button from the previous task is a toggle, if pressed the LED is on, then if pressed again the LED becomes off
