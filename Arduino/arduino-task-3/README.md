# Arduino task 3

for this task we have to combine an LCD screen, communicate to it with I2C protocol, with an LDR, we right to the screen the brightness level and **BRIGHT** if the read is above a certain threshold, otherwise **DARK**

the project will utilize the `LiquidCrystalI2C` library by `johnrickman`, the library sourcecode can be found [here](https://github.com/johnrickman/LiquidCrystal_I2C/)
